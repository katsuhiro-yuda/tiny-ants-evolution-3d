# Tiny Ants: Evolution 3D

遺伝的特徴を持つ蟻が3Dの箱庭で自律的に生存・繁殖・進化し、やがて巣とコロニーを形成する様子を眺めるシミュレーションです。

ブラウザ内で完結します。バックエンド、ログイン、外部APIはありません。セーブデータは端末内にのみ保存され、通常利用中に外部へ送信されることはありません。

> **開発状況: Phase 0（技術検証）完了**
> 3Dフィールド、カメラ操作、100匹の簡易蟻の InstancedMesh 描画、固定タイムステップ、シード付き乱数、性能計測HUDまで動作します。
> 採食・エネルギー・遺伝・コロニーは未実装です（Phase 1以降）。

## コンセプト

プレイヤーは蟻を直接操作しません。餌、障害物、水場、初期集団などを配置して環境を間接的に変え、その結果として起きる現象を観察します。

- 共通祖先から、草食型・肉食型・雑食型・高速型・重装甲型などが自然に分岐する
- 能力には必ずコストがあり、単一の最強個体へ収束しにくい
- 形質の変化が姿・色・動きへ反映される
- 筋書きを与えなくても、シミュレーションから物語が生まれる
- 社会性の進化によって、単独行動から巣・フェロモン経路・コロニーへ発展する

固定の勝利条件はありません。体験の比率は観察70%・環境介入30%を想定しています。

## MVPの範囲

コロニー形成までをMVPとします。

**含むもの** — ローポリ3Dフィールドと斜め上視点カメラ / 初期100匹の蟻 / 植物性餌・小昆虫・死骸・水場・岩 / 探索・採食・逃走・捕食・休息・繁殖・帰巣 / 遺伝と突然変異と自然選択 / 形質から算出する食性 / 巣とコロニーと餌の運搬・共有 / 餌フェロモン / 複数コロニーの共存 / 統計とイベントログ / 一時停止と速度変更 / シード付き世界生成 / IndexedDB自動保存とJSON入出力 / PWAオフライン利用

**含まないもの** — 人間型文明・通貨・技術研究 / 蟻への直接命令 / オンライン対戦やアカウント同期 / 写実的な蟻や厳密な生物学的再現 / 季節・天候・災害 / 本格的な外交・同盟・戦争 / モバイル完全対応

詳細は仕様書の「2. MVPの範囲」を参照してください。

## アーキテクチャ

UI・描画・シミュレーション・永続化を分離します。シミュレーションエンジンは純粋なTypeScriptで、DOMなしで単体テストできる状態を保ちます。

```
UI / React
    ↓ 操作・表示
Application State (Zustand)
    ↓ コマンド・スナップショット
Simulation Engine (純粋TypeScript)   ↔   Persistence / IndexedDB
    ↓ 状態
Renderer / Three.js
    ↓
WebGL 2
```

主な設計上の制約:

- 乱数はシード付きジェネレータを注入し、同一シードで同一の世界を再現できるようにする
- シミュレーションは描画から分離した固定タイムステップで進める
- バランス値・係数は `src/simulation/config` へ集約し、純粋関数として計算する
- 近傍探索はUniform Grid / Spatial Hashを使い、全個体総当たりは行わない
- 蟻の描画は `InstancedMesh` を基本とする
- 保存データはスキーマバージョンを持ち、読み込み時に検証する

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型検査
npm run lint       # Lint
npm run test       # 単体テスト（Vitest）
npm run build      # 本番ビルド
npm run format     # Prettier で整形
```

単一テストの実行は `npx vitest run src/simulation/engine/world.test.ts`。
E2E（`npm run test:e2e`）はPhase 1でPlaywrightを導入してから追加します。

### 実装Phase

| Phase | 内容         | 完了条件                                                                   |
| ----- | ------------ | -------------------------------------------------------------------------- |
| 0 ✅  | 技術検証     | 100体の簡易蟻を安定表示し、同一シードで同じ初期配置を再現できる            |
| 1     | 生存         | 蟻が視界内の餌を探して食べ、エネルギー切れまたは寿命で死亡する             |
| 2     | 進化         | 50世代以上で形質分布の変化を確認でき、同一条件で再現可能である             |
| 3     | 捕食と生態系 | 草食・肉食・雑食の各傾向が固定クラスなしで発生し、捕食と資源循環が機能する |
| 4     | コロニー     | 2つ以上のコロニーが共存でき、所属個体が巣とフェロモン経路を利用する        |
| 5     | 保存と仕上げ | 再読み込み後も同じ状態から再開でき、初回キャッシュ後はオフライン起動できる |

各Phaseの完了時に型検査・Lint・テスト・ビルドを実行します。

## 動作環境

最新版のChrome、Edge、Firefox（デスクトップ）。WebGL 2が必要で、非対応環境では説明画面を表示します。Safariは主要機能のみ確認し、一部差異を許容します。

性能目標は100匹で60 FPS、500匹で30 FPS以上を努力目標とします。
