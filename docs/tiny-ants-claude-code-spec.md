## 1. プロダクト概要

`Tiny Ants: Evolution 3D` は、遺伝的特徴を持つ蟻が3Dの箱庭で自律的に生存、繁殖、進化し、やがて巣とコロニーを形成する様子を眺めるシミュレーションである。

プレイヤーは蟻を直接操作しない。餌、障害物、水場、初期集団などを配置し、環境を間接的に変える。その結果として起きる適応、種の分岐、個体数周期、捕食、絶滅、コロニー形成を観察する。

### 中核となる体験

- 共通祖先から、草食型、肉食型、雑食型、高速型、重装甲型などが自然に分岐する。
- 能力には必ずコストがあり、単一の最強個体へ収束しにくい。
- 形質の変化が姿、色、動きへ反映される。
- プレイヤーが筋書きを与えなくても、シミュレーションから物語が生まれる。
- 社会性の進化によって、単独行動から巣、フェロモン経路、コロニーへ発展する。

## 2. MVPの範囲

### 含める機能

- ローポリ調の3Dフィールド
- 回転、ズーム、移動ができる斜め上視点カメラ
- 初期値100匹の蟻
- 植物性餌、小昆虫、死骸、水場、岩
- 探索、採食、逃走、捕食、休息、繁殖、帰巣
- エネルギー、成長、加齢、死亡
- 遺伝、突然変異、自然選択
- 形質から算出する草食、肉食、雑食傾向
- 速度、体格、装甲、視野などのトレードオフ
- 巣、所属コロニー、餌の運搬と共有
- 餌フェロモンの設置、減衰、追従
- 複数コロニーの共存と条件付きの小競り合い
- 個体、巣、コロニーの選択と詳細表示
- 個体数、世代、生態型比率、平均形質の統計
- 一時停止、1倍、2倍、4倍

- IndexedDBへの自動保存

- PWAによるオフライン利用

### MVPに含めない機能

- 季節、天候、災害
- 本格的な外交、同盟、戦争
- モバイル完全対応
- WebGPU必須機能

## 3. ゲームループ

1. シードから生成された世界と祖先集団を表示する。
2. 蟻が自律的に餌を探し、生存し、繁殖する。
3. 子へ遺伝形質が継承され、小さな突然変異が加わる。
4. 環境に適した形質を持つ個体が相対的に増える。
5. プレイヤーは餌や障害物などを配置して環境へ介入する。
6. 社会性が高い集団は巣とコロニーを形成する。
7. プレイヤーは個体、系統、コロニー、統計、出来事を観察する。
8. 世界は自動保存され、後日再開できる。

固定の勝利条件は設けない。全個体が死亡した場合は絶滅を通知し、同じ世界への祖先再投入または新規世界作成を選択できるようにする。

## 4. 世界モデル

### フィールド

- 正方形の有限フィールド
- 推奨初期サイズ: 100 × 100ワールド単位
- 地形: 平原、水場、植物群、岩
- 蟻は境界を越えない
- シード値から初期状態を再現可能にする

### 資源

| 資源 | 特徴 | 再生・発生 |
|---|---|---|
| 植物性餌 | 安定、低～中カロリー | 周辺条件と時間で再生 |
| 小昆虫 | 移動、高カロリー | 設定に従い発生 |
| 死骸 | 肉食・雑食向け、高カロリー | 蟻・昆虫の死亡時 |
| 水 | 地形・植物分布に影響 | MVPでは枯渇しない |

### 時間

- 描画とは分離した固定タイムステップで計算する。
- 速度は停止、1倍、2倍、4倍。
- ブラウザがバックグラウンドになったら停止する。
- 復帰時に経過時間を一括計算しない。

## 5. 蟻のデータモデル

### 遺伝形質

各値は原則 `0.0～1.0` とする。

| フィールド | 効果 | コスト | 見た目 |
|---|---|---|---|
| speed | 最大移動速度 | 移動消費増 | 脚が長く細い |
| bodySize | 攻撃、防御、蓄積量 | 基礎代謝増、旋回低下 | 全身サイズ |
| armor | 被ダメージ軽減 | 速度低下、代謝増 | 胴体が厚い |
| visionRange | 探索範囲 | 感覚消費増 | 目・触角 |
| attack | 捕食・戦闘能力 | 攻撃消費増 | 顎が大きい |
| plantDigestion | 植物の栄養効率 | 肉消化との両立コスト | 緑系差し色 |
| meatDigestion | 肉の栄養効率 | 植物消化との両立コスト | 赤系差し色 |
| metabolism | エネルギー変換効率 | 瞬発性能との両立コスト | 原則なし |
| fertility | 繁殖しやすさ | 子の初期エネルギー低下 | 腹部形状 |
| longevity | 寿命 | 成熟が遅い | 明度 |
| sociability | 巣・集団への帰属 | 単独探索効率低下 | 群れ方 |
| pheromoneSensitivity | 経路追従能力 | 感覚消費増 | 触角 |
| territoriality | 他群への攻撃傾向 | 戦闘リスク増 | 姿勢・彩度 |
| sharingRate | 巣へ持ち帰る割合 | 即時回復量低下 | 運搬行動 |

### 必須の型

```ts
type AntId = string;
type ColonyId = string;
type LineageId = string;

interface Genome {
  speed: number;
  bodySize: number;
  armor: number;
  visionRange: number;
  attack: number;
  plantDigestion: number;
  meatDigestion: number;
  metabolism: number;
  fertility: number;
  longevity: number;
  sociability: number;
  pheromoneSensitivity: number;
  territoriality: number;
  sharingRate: number;
}

interface AntEntity {
  id: AntId;
  parentId?: AntId;
  lineageId: LineageId;
  colonyId?: ColonyId;
  generation: number;
  genome: Genome;
  position: Vec3;
  velocity: Vec3;
  age: number;
  energy: number;
  health: number;
  state: AntBehaviorState;
  targetId?: string;
}
```

必要に応じて型を追加してよいが、UIおよび描画専用の値をシミュレーションモデルへ混在させないこと。

## 6. 遺伝と進化

### 遺伝

- MVPでは親1個体から子を生成する簡略化モデルとする。
- 子は親の全形質を継承する。
- 各形質へ平均0の小さな変異を加える。
- 低確率で通常より大きな変異を発生させる。
- すべての値を0.0～1.0に収める。
- `id`、`parentId`、`lineageId`、`generation` を記録する。

### 生態型

食性は固定クラスとして実装しない。形質から表示用ラベルを計算する。

- 草食型: `plantDigestion - meatDigestion` が閾値以上
- 肉食型: `meatDigestion - plantDigestion` が閾値以上
- 雑食型: 両者の差が閾値未満

速度、装甲、体格、視野、繁殖力について、同世代または現存個体の上位20%を補助ラベルとして扱う。個体には食性ラベル1つ、特徴ラベルを最大2つ表示する。

### トレードオフ

全能力が最大化する設計は禁止する。最低限、次を実装する。

- 高速化 → 移動時のエネルギー消費増
- 大型化 → 基礎代謝増、旋回低下
- 重装甲化 → 速度低下、基礎代謝増
- 視野拡大 → 感覚のエネルギー消費増
- 高繁殖力 → 子の初期エネルギー低下
- 長寿命 → 成熟までの時間増
- 肉食特化 → 植物から得られる栄養低下
- 草食特化 → 肉から得られる栄養低下

計算係数は `simulation/config` 以下へ集約し、テスト可能な純粋関数にする。

## 7. 行動モデル

### 状態

```text
Idle
Explore
SeekFood
Eat
Hunt
Flee
CarryFood
FollowPheromone
ReturnNest
Rest
Reproduce
```

### 意思決定

- 空腹度、視界内の餌、捕食リスク、巣への距離、社会性から行動スコアを計算する。
- 最高スコアの行動を基本とするが、小さなランダム性を加える。
- 視界外の対象位置を直接参照しない。
- 個体ごとに意思決定タイミングをずらす。
- 毎描画フレームで全個体の意思決定を行わない。

### 捕食

- 肉食傾向、空腹度、攻撃力、体格、縄張り意識が攻撃判断へ影響する。
- 同一コロニーの個体は攻撃しない。
- 防御側の装甲、体格、速度が生存・逃走へ影響する。
- 攻撃と追跡には大きなエネルギーコストを持たせる。
- 死亡個体は時間制限付きの死骸資源になる。

## 8. 巣とコロニー

### 成立条件

社会性の高い近縁個体が、狭い範囲へ一定数、一定時間滞在すると巣候補を生成する。必要な個体数、範囲、時間、社会性閾値は設定値にする。

### 巣の機能

- 所属個体の帰還地点
- 運搬された餌の蓄積
- 休息時の消費軽減
- 蓄積餌による繁殖支援
- コロニーIDと表示色
- 個体数、資源量、平均形質の集計

### フェロモン

- 餌を巣へ持ち帰る個体が経路へフェロモンを残す。
- フェロモンは時間で減衰する。
- 感度の高い所属個体が濃度勾配を追う。
- 表示のオン・オフを切り替えられる。
- MVPは餌フェロモンだけを対象とする。

### コロニー間関係

- 同一コロニーは餌と巣を共有する。
- 別コロニーは共有しない。
- 縄張り意識、空腹、資源競合によって小競り合いが発生する。
- 宣戦、外交、同盟は実装しない。

### カメラ

- ドラッグ: 回転
- ホイール: ズーム
- 右ドラッグまたは修飾キー + ドラッグ: 平行移動
- 選択個体を追跡する機能

## 11. 3D表現

- 温かみのあるローポリ・ジオラマ調
- 蟻は頭、胸、腹、6本脚、触角を単純形状で表現
- 体格、脚、胴体、顎、触角、差し色に形質を反映
- コロニー色と食性の差し色を区別
- 色だけでなく形、サイズ、ラベルでも違いを示す
- 蟻の大量描画は `InstancedMesh` を基本とする
- 写実的なテクスチャや重い3Dモデルは使用しない

## 12. 技術要件

### 採用スタック

| 領域 | 技術 |
|---|---|
| ビルド | Vite |
| 言語 | TypeScript（strict） |
| UI | React |
| 3D | Three.js + React Three Fiber |
| 3D補助 | @react-three/drei |
| UI状態 | Zustand |
| 永続化 | IndexedDB + Dexie |
| テスト | Vitest + Testing Library + Playwright |
| PWA | vite-plugin-pwa |
| 品質 | ESLint + Prettier |

依存ライブラリを変更または追加する場合は、必要性、代替案、バンドルサイズへの影響を着手前に説明すること。

### アーキテクチャ

```text
UI / React
    ↓ 操作・表示
Application State
    ↓ コマンド・スナップショット
Simulation Engine（純粋TypeScript）
    ↓ 状態
Renderer / Three.js
    ↓
WebGL 2

Simulation Engine
    ↔ Persistence / IndexedDB
```

- UI、描画、シミュレーション、永続化を分離する。
- シミュレーションは可能な限りDOMなしで単体テスト可能にする。
- 乱数生成器を注入可能にする。
- 初期実装はメインスレッドでもよいが、Web Workerへ移行できるAPI境界を設ける。
- 保存データにスキーマバージョンを持たせる。

### 推奨ディレクトリ

```text
src/
  app/
  components/
  world/
    scene/
    renderers/
    camera/
  simulation/
    engine/
    entities/
    systems/
    behaviors/
    genetics/
    colony/
    resources/
    spatial/
    config/
  state/
  persistence/
  analytics/
  workers/
  test/
```

### 空間探索

- 全個体同士の総当たりは禁止する。
- Uniform GridまたはSpatial Hashを使用する。
- 餌、敵、仲間、巣の探索は近傍セルだけを対象にする。

### 保存

- IndexedDBへ一定間隔で自動保存する。
- シード、時刻、設定、蟻、資源、巣、フェロモン、系統、統計要約、イベントを保存する。
- JSONのエクスポートとインポートを実装する。
- 読み込み時にスキーマ、サイズ、型、値域を検証する。

## 13. 非機能要件

### 性能

- 最新版ChromeまたはEdgeを基準とする。
- 100匹で60 FPSを目標とする。
- 500匹で30 FPS以上を努力目標とする。
- FPS、描画時間、シミュレーション更新時間を開発モードで確認可能にする。
- 100匹を10分実行して継続的なメモリ増加がないことを確認する。

### 対応環境

- 最新版Chrome、Edge、Firefoxのデスクトップ
- WebGL 2を基本とする
- WebGL 2非対応時は説明画面を表示する
- Safariは主要機能を確認するが、一部差異を許容する

### アクセシビリティ

- UI操作をキーボードで選択できる。
- 状態を色だけで表現しない。
- `prefers-reduced-motion` を尊重する。
- UI文字はWCAG AA相当のコントラストを目標にする。

### プライバシー

- 外部API、解析タグ、広告、アカウントを使用しない。
- セーブデータは端末内だけに保存する。
- 通常利用中に外部へデータ送信しない。
